# 项目式学习路线

目标不是一次读懂全部代码，而是每完成一个小改动，就掌握一组 ROS 2 概念。

## 阶段 1：先把系统跑起来

任务：启动 `simulation.launch.py`，在 RViz2 中找到 RobotModel、末端 Path 和训练方块。

你会学到：工作区、source、Launch、节点、话题、TF、RViz2。

验收：

```bash
ros2 node list
ros2 topic echo /joint_states --once
ros2 run tf2_ros tf2_echo base_link tool_tip
```

## 阶段 2：只用命令行操作系统

任务：暂停、恢复、重置仿真，改变夹爪开度，观察话题频率。

你会学到：消息、服务、参数、QoS 和仿真时间。

验收：能够解释“话题适合连续数据，服务适合一次请求”的原因。

## 阶段 3：读懂标准轨迹 Action

任务：运行 `demo_sequence`，修改一个路点和到达时间，然后故意提交一个越界角度观察拒绝结果。

重点文件：

- `pybullet_arm_control/trajectory.py`
- `pybullet_arm_control/trajectory_controller.py`
- `pybullet_arm_control/demo_sequence.py`

你会学到：Action 生命周期、反馈、取消、分段插值、关节限制。

验收：预设轨迹成功；错误轨迹被拒绝；取消后机械臂保持当前位置。

## 阶段 4：理解机器人模型和物理引擎

任务：修改连杆长度或质量，重新构建并对比 RViz2 与 PyBullet 行为。

重点文件：

- `pybullet_arm_description/urdf/lab_arm.urdf.xacro`
- `pybullet_arm_sim/bullet_world.py`

你会学到：URDF/Xacro、惯量、碰撞体、关节限制、位置控制和固定时间步。

验收：`check_urdf` 通过，单元测试通过，两个显示端仍使用同一模型。

## 阶段 5：逆运动学与任务空间

任务：修改 `ik_demo` 的目标坐标，绘制可达与不可达点，加入末端误差复核。

你会学到：正运动学、数值 IK、种子解、奇异位形和工作空间。

验收：给出目标位置、实际位置和欧氏误差，并正确拒绝误差过大的解。

## 阶段 6：实现抓取状态机

任务：新增独立任务节点，完成预抓取、靠近、闭合、抬升、移动、释放。

建议交付物：

- 状态机图；
- 可配置抓取点；
- 超时与取消；
- 接触检测日志；
- 至少三次可重复的无界面测试。

## 阶段 7：升级为工程化控制栈

任务：引入 `ros2_control` 和 MoveIt 2，保留当前控制器作为对照基线。

你会学到：硬件抽象、控制器管理器、规划场景、碰撞检查和轨迹执行。

验收：MoveIt 2 规划轨迹可通过标准控制器发送到同一个 PyBullet 世界。

## 阶段 8：形成第一个完整项目

最终题目建议：桌面机械臂多物体分拣平台。

最低功能：

1. 随机生成多种颜色或尺寸的物体；
2. 获取目标位姿；
3. 规划并执行抓取；
4. 按规则放入不同区域；
5. 记录成功率、耗时和失败类型；
6. 提供一键启动、自动测试、演示视频和技术报告。

这个阶段再加入相机、感知或强化学习。先确保确定性的状态输入版本稳定，避免同时调试感知、规划和控制三个未知环节。
